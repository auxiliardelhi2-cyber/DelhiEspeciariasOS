# Delhi Especiarias OS — CLAUDE.md

Sistema operacional (V1) da Delhi Especiarias no Claude.

## Regras iniciais

1. **Leia este CLAUDE.md antes de trabalhar.**
2. **Consulte `Context/` antes de responder** sobre empresa, clientes, estratégia, marca ou pessoas.
3. **Use `Documents/`** para documentos gerais e oficiais.
4. **Use `Projects/`** para contexto específico de projetos.
5. **Use `Meetings/`** para resumos, decisões e próximos passos.
6. **Use `Daily/`** para registros rápidos.
7. **Use `Skills/`** para processos repetitivos.
8. **Nunca invente fatos nem preencha lacunas sem avisar.** Onde faltar informação, use `[PENDENTE DE VALIDAÇÃO]`.

## Estrutura

- `Context/` — organization, brand, strategy, icp, pessoas-chave, Profile
- `Documents/` — documentos gerais e oficiais
- `Projects/` — contexto por projeto
- `Meetings/` — resumos, decisões, próximos passos
- `Daily/` — registros rápidos
- `Skills/` — processos repetitivos (ex.: `onboarding-contexto/`)
